# Shabyt

Қойшықараева Шолпанның көркем еңбек пен халық ауыз әдебиетін ықпалдастыру жобасына арналған қазақша интерактивті сайт.

## Іске қосу

```sh
npm install
npm run dev
```

Браузерде http://localhost:3000 мекенжайын ашыңыз.

```sh
npm run typecheck
npm run build
npm start
```

## Беттер

- `/` — таныстыру, жоба авторы, үш бағыт.
- `/ertegiler` — презентациядағы екі ертегі видеосы, суреттері бар алты ертегінің қысқаша таныстырылымы мен толық нұсқасына сілтемелер.
- `/zhumbaktar` — бес Word файлының материалдары, жанр сүзгісі, іздеу, жауапты ашу, табиғат видеосы және шешілген жұмбақтарды аккаунтта белгілеу.
- `/oyu-ornek` — презентациядағы үш оюдың суреті, аңызы және видеосы, қосымша тоғыз стильденген оқу үлгісі мен Wikipedia іздеуі.
- `/chat` — қазақша ЖИ көмекші; ертегі, жұмбақ және ою-өрнек бойынша сөйлесу.
- `/login`, `/register` — email/құпиясөз немесе Google арқылы кіру және оқушы/мұғалім тіркелуі.
- `/profile` — оқушы үшін тапсырмалар, жауап жіберу, мұғалім пікірін оқу және жеке прогресс; мұғалім үшін оқушылар тізімі, мониторинг, тапсырма жариялау мен жауаптарға пікір жазу. Бұрынғы браузерлік прогресс оқушы алғаш кіргенде көшіріледі.

## Firebase тіркелуін іске қосу

Firebase жобасы: `shabyt-a12b0`. Клиент конфигурациясы `lib/firebase-client.ts` файлында; ол жария Firebase web config болып табылады. Firebase Console → Authentication → Sign-in method бөлімінде **Email/Password** және **Google** провайдерлерін қосыңыз. Authentication → Settings → Authorized domains бөліміне жергілікті `localhost` пен жарияланатын Vercel/жеке домендерді енгізіңіз.

Firestore Database құрып, Firebase Console → Firestore Database → Rules ішіне `firestore.rules` файлының мазмұнын жариялаңыз. Ережелер оқушыға өз профилі мен жауабын, мұғалімге оқушылар профильдерін және тапсырма жауаптарын оқуға рұқсат береді. Тапсырмалар `assignments/{id}`, жауаптар `submissions/{assignmentId}_{studentId}` құжаттарында сақталады. Тапсырма барлық тіркелген оқушыға беріледі; сыныптарға бөлу әлі қосылмаған.

Мұғалім коды `lib/teacher-code.ts` файлында: `SHABYT-USTAZ-2026`. Оны сол жерден өзгертуге болады. Бұл қарапайым тіркелу коды, қауіпсіз рөл шектеуі емес: браузердегі JavaScript кодын қарайтын адам оны тауып, өзін мұғалім етіп тіркей алады. Мұғалім рөлі оқушылар профильдері мен жауаптарын көруге рұқсат беретіндіктен, бұл кодты нақты құпия рөл бақылауы ретінде қолдануға болмайды.

Профиль мен прогресс Firestore-да `users/{uid}` құжатына жазылады. Бір аккаунтпен кірген басқа құрылғыда деректер синхрондалады.

## ЖИ чатты іске қосу

`.env.example` файлын `.env.local` ретінде көшіріп, `GROQ_API_KEY` мәніне өз Groq API кілтіңізді жазыңыз. Кілт тек серверде оқылады және браузерге берілмейді. `GROQ_MODEL` міндетті емес; әдепкі мәні `openai/gpt-oss-20b`. Кілтсіз чат беті ашылады, бірақ сұраққа жауап беру кезінде түсінікті ескерту көрсетеді.

Презентациядағы видеолар 5–6 секундтық қысқа анимациялар. Ертегі видеоларында аудиожол жоқ; түпнұсқа қалпында сақталды.

Материалдар `content/`, презентациядан алынған суреттер мен алты MP4 видео `public/media/` ішінде. Түпнұсқа құжаттар өзгертілмеді. Тарихи жанр файлындағы екі нақыл сөз жұмбақ ретінде емес, халық даналығы ретінде көрсетіледі. Мақта қыз слайдында жеке видео жоқ, сол ертегі оқу бөлімінде берілген.

Автор аты `app/page.tsx` пен `app/layout.tsx` ішінде. Мәтіндер мен материалдарда файл ішіндегі жоба сипаттамалары дерек ретінде пайдаланылды.

## Vercel

Репозиторийді GitHub-қа жүктеп, Vercel-де Import Project арқылы таңдаңыз. Framework Preset: Next.js. Root Directory: жоба түбірі. Build Command: `npm run build`. Vercel Project Settings → Environment Variables ішінде ЖИ чатқа арналған `GROQ_API_KEY` орнатыңыз; қажет болса `GROQ_MODEL` мәнін өзгертіңіз. Доменді Firebase Authentication → Authorized domains тізіміне де қосыңыз. Deploy аяқталғаннан кейін доменді Project Settings → Domains бөлімінде қосыңыз. Бұл жұмыс барысында сайт жарияланған жоқ.

Суреттер мен видеолар сайттың өзінен беріледі. Видео автоматты ойнатылмайды; мобильді құрылғыларда да пайдаланушы өзі іске қосады. Қозғалысты азайту баптауы қолданылады.
